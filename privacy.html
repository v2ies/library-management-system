This is a class project, built by a student group (contact: group4@uphsd.edu.ph) at University of Perpetual Help System DALTA — Molino Campus, for an academic exercise. It is not an official university system, and UPHSD does not operate, endorse, or take responsibility for it.

1. What this system stores

When you register or use the Student or Admin side of this app, the following may be stored:

  • Full name, Student ID, year level, section, and course (student registration)
  • Account password (see the note below — please don't reuse a real/important password)
  • Optional profile photo you upload (max 2MB)
  • Book requests, borrow/return history, and due dates
  • Display theme preference (light/dark)

2. Where it's stored — the important part

This app has no server and no database. Everything above is saved only in your own web browser, using the browser's built-in localStorage and sessionStorage (not cookies). Nothing you enter is transmitted over the internet or shared with any third party — because there's no "us" on the other end receiving it.

This means: data doesn't sync between devices or browsers; clearing your browser's site data deletes it permanently; and anyone with access to that browser/device can view what's stored there, same as with any other browser-only demo app.

3. A note on the password field

Because there's no server, there's no way to secure the password field the way a production system would. Treat this as a demo account, not a real one — use a throwaway password you don't use anywhere else.

4. Cookies

This site doesn't use cookies. It uses localStorage (persistent until cleared) and sessionStorage (cleared when the tab/browser closes) purely to run the app itself — no tracking or advertising use, so no cookie-consent banner applies here.

5. Third parties and analytics

This site loads no analytics, tracking pixels, or embeds from outside services (other than the Google Fonts stylesheet used for the site's typeface). If that changes in a later version, this notice should be updated to say what's added and why.

6. Your choices

  • Delete your own data any time by clearing your browser's site data for this page.
  • Ask an admin (the class group) to remove a student record from the demo.
  • Don't enter information you wouldn't want visible to anyone using the same device/browser.

7. Children's data

This app is intended for college-level students registering with a UPHSD-format Student ID; it's not directed at children.
